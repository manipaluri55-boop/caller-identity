# Caller Identity — Native Android Application

**Package:** com.calleridentity.utility
**Target Notification Source:** com.driveu.partner
**Architecture:** Native Android (Kotlin + Jetpack Compose + NotificationListenerService)

### Quick Build in Android Studio:
1. Open this folder in Android Studio Ladybug/Hedgehog+.
2. Wait for Gradle sync to finish.
3. Build APK with: ./gradlew assembleDebug
4. Install: adb install app/build/outputs/apk/debug/app-debug.apk
